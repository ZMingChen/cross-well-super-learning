> ## Computer Code Availability
> The reproducible implementation of the grouped and class-calibrated Super Learning workflow, including a synthetic demonstration dataset, installation instructions, and a release-audit script, is publicly available at **https://github.com/ZMingChen/cross-well-super-learning**, release **v0.2.0**. Repository ignore rules and an automated release audit block these file classes before publication. The underlying field data are subject to data-owner restrictions and may be accessed only with permission from the data owner. The published repository provides the complete non-sensitive workflow and synthetic data needed to execute the demonstration.
